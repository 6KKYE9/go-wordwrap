按宽度折行的小工具，中文按两个宽度算，避免半角数字和全角汉字混排时错位。从标准输入读，折完写到标准输出。拉丁扩展字母（éñü）按 1 宽算，只有中文、日文、韩文、全角符号这些才占 2 宽。

用法：
  echo 一段很长的文字 | go-wordwrap -w 40
  cat 文章.txt | go-wordwrap -w 60 -i "  "        # 每行缩进两个空格
  cat 文章.txt | go-wordwrap -w 60 -t "> "        # 每行加 "> " 前缀
  cat 文章.txt | go-wordwrap -s                   # 按段落折行，段间空一行
  echo 整段文字 | go-wordwrap -w 0 -t "# "        # 不折行，只加前缀

参数：
  -w 宽度     折行宽度，中文算两个宽度；0 表示不折行（只加缩进/前缀）
  -i 缩进     每行缩进，比如两个空格或制表符
  -t 前缀     行前缀，放在缩进之后、正文之前
  -s          按段落折行：以空行为界分段，段与段之间空一行
  也可以把文件路径当参数直接传进来折行
